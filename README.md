# 🧮 Java Calculator (Precourse)

문자열에 포함된 숫자를 구분자를 기준으로 분리하여 합계를 계산하는 프로그램입니다.  
커스텀 구분자를 지정할 수 있으며, 잘못된 입력 시 예외를 발생시킵니다.

---

## 🚀 기능 요구사항

1. **문자열 분리**
   - 기본 구분자: 쉼표(`,`), 콜론(`:`)
2. **커스텀 구분자 지정**
   - 형식: `"//[구분자]\n[문자열]"`  
     예: `//;\n1;2;3`
3. **합계 계산**
   - 구분자를 기준으로 숫자를 추출하고, 모든 수의 합을 반환

---

## 💡 입출력 예시

| 입력 | 출력 |
|------|------|
| `"1,2,3"` | `결과 : 6` |
| `"//;\n1;2;3"` | `결과 : 6` |

---

## ⚙️ 예외 처리

- 사용자가 잘못된 형식의 문자열을 입력한 경우  
  → `IllegalArgumentException` 발생  
  → 애플리케이션 종료

---

## 🧠 트러블슈팅

- **문제:** `\n` 처리 과정에서 문자열 split이 예상대로 작동하지 않음  
- **해결:** 정규식을 사용하여 커스텀 구분자 패턴 추출 (`Pattern.compile("//(.)\n(.*)")`)
